Status is computed by enumerating every remaining group result. "Through" and "Eliminated" are guaranteed regardless of goal difference. A team that can only reach 3rd is shown as alive — but 3rd-place qualification depends on the other 11 groups, so it is never shown as "in" here.

How to make this live (and correct)

1 — Verify the tiebreaker order. Press reporting splits on whether 2026 uses head-to-head first or overall goal difference first. Open FIFA's official tournament regulations (Article 13) and confirm. Then set TIEBREAKER_MODE at the top of the script to 'h2h_first' or 'gd_first'. This changes who advances in any group where teams tie on points.

2 — Replace the data. Edit the GROUPS object. Each group is 4 teams and its 6 matches. Leave hs/as as null for unplayed games; enter integers as games finish. Everything (tables, in/out status, best/worst, 3rd-place race) recomputes from that one object.

3 — Bracket 3rd-place assignment. The 8 group winners that face a third-placed team draw from a 495-row published table (Annex C of the regulations). I did not hand-type 495×8 cells — copy-paste error would silently corrupt the bracket. Instead, generate ANNEX_C from the source and paste it in. Until then the bracket fills winners/runners-up and shows each 3rd slot's eligible groups.

Generator: build ANNEX_C from the Wikipedia/FIFA table 
// Run once in Node after pasting the raw "Combinations" table (495 lines like:
//   "1: E; F; G; H; I; J; K; L; 3E; 3J; 3I; 3F; 3H; 3G; 3L; 3K")
// Column order of the 8 assignments is: 1A,1B,1D,1E,1G,1I,1K,1L
const raw = `PASTE_495_LINES_HERE`;
const COLS = ['A','B','D','E','G','I','K','L'];
const out = {};
for (const line of raw.trim().split('\n')) {
  const t = line.split(':')[1].split(';').map(s=>s.trim()).filter(Boolean);
  const src = t.slice(0,8).sort().join('');        // e.g. "EFGHIJKL"
  const asg = t.slice(8,16).map(x=>x.replace('3','')); // group letters
  out[src] = Object.fromEntries(COLS.map((c,i)=>[c, asg[i]]));
}
console.log('const ANNEX_C = ' + JSON.stringify(out) + ';');

Known limitations (don't overclaim):

  • 3rd-place "advances?" depends on all 12 groups at once. This page shows finish-position within a group exactly, and a current 3rd-place cutline as a snapshot — not a guarantee.
  • Where teams tie on points and the order turns on goal difference of hypothetical future scorelines, status shows the honest range rather than asserting a lock.
  • Exotic 3-way head-to-head mini-table ties use a single-pass resolve; FIFA re-applies criteria among still-tied teams. Rare; flagged here so you know.
  • R16 Match 96 (W85 v W87) is inferred from the bracket structure — confirm against FIFA's schedule.
